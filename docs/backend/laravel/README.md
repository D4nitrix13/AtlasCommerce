# `docs/backend/laravel/`

Cómo se usa el framework Laravel en este proyecto: patrones de
arquitectura (Services, Actions, Resources) y herramientas de
desarrollo (Pint, Larastan, composer).

## Contenido

- `components.md` — los componentes de arquitectura Laravel que usa
  este proyecto: Services, Repositories, Resources, FormRequests,
  y el namespace `Core\` para código compartido.
- `composer.md` — herramientas de Composer: scripts custom,
  plugins de desarrollo, autoload.

## Audiencia

Devs backend nuevos en el proyecto. Devs que vienen de otro
proyecto Laravel y necesitan entender las convenciones locales.
