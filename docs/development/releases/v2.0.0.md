# Release notes

## v2.0.0 — 2026-08-02

Corte de Fase 5. Cierra la migración a `app/Core/` y elimina el wrapper
legacy del store context.

### Cambios incompatibles

- `App\Services\Stores\StoreContextService` eliminado. Importar
  `Core\Tenant\Application\StoreContextService` en su lugar.
- El alias cruzado de contenedor en `AppServiceProvider` deja de existir;
  la resolución es directa vía el namespace `Core`.
- Migración RLS `2026_08_02_000003_enable_row_level_security` aplicada:
  tablas con `store_id` usan `FORCE ROW LEVEL SECURITY`. Roles de
  aplicación deben ser `NOSUPERUSER` y `NOBYPASSRLS`.

### Nuevas características

- Workspaces pnpm `frontend/packages/themes/{panda,kitsune,mm-boutique,morales-store}`.
- Plugin Composer de referencia `d4nitrix13/ecommerce-plugin-erp` con
  auto-discovery, activación por tenant y migración de `erp_connections`.
- `Core\Shared\Events\{Event, EventBus, InProcessEventBus}` como bus
  síncrono de eventos de dominio.
- `Core\Tenant\Application\RlsContextService` con `set_store_id`/`clear`
  por request y soporte para `tenants:bootstrap`.
- `RlsPolicyTest` documenta metadata RLS, policies y excepción de
  `store_domains`.

### Guías de contribuidores

- `docs/development/core-migration.md` — receta de migración a
  `app/Core/`.
- `docs/development/plugins.md` — ciclo de vida de plugins Composer.

### Calidad

- Backend: 213 tests, 638 assertions pasando.
- Frontend: 40 tests Vitest pasando y `astro build` completo.
- Lint/Pint/Prettier/markdownlint del alcance modificado pasan.
- PHPStan global mantiene la deuda preexistente no relacionada con
  Fase 5; se documenta para F6.
